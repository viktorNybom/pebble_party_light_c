# pebble_party_light_c
App for Pebble smartwatch

Uses the RGB backlight of the Pebble Time 2, so the app only works for the Time 2.
Changes backlight color to a new backlight color in the set BPM.
Colors are random from: Red, Blue, Green, Cyan, Magenta, Yellow, Warm White and Amber. 

Middle button: set BPM (tap in a four-beat rhythm).
Up button: click or hold to increase BPM (decrease the blink interval by 2 ms).
Down button: click or hold to decrease BPM (increase the blink interval by 2 ms).

Enjoy the party!
